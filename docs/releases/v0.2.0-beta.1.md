# ObsidianPlanner v0.2.0-beta.1 — 逐条选择同步操作

## 新增与调整

- **新安排默认 Add**；根据本机历史识别的旧安排默认 **Skip**，包括日记中已经修改的旧安排。
- 每条旧安排可以选择 **Update existing** 或 **Add again (new copy)**。
- Update existing 会按当前日记覆盖关联条目的标题、时间、完成状态及本次通知设置；只想保留手机端状态时选 Skip。
- Add again 会保留旧条目并生成新副本，后续更新关联最新副本，普通重复同步不会继续自动新增。
- 未变化的内容重新预览时保留选择；源内容、日期范围或时区变化后清除旧选择。同步前检测到源变化时要求重新检查，不直接执行旧选择。
- 结果分别显示主动跳过和失败／未解决数量。匹配冲突中的显式 Skip 不再被当成错误；旧副本不会出现在后续匹配候选中。
- 日历与提醒事项分别保存通知历史，避免只同步一端后丢失另一端的通知设置记录。

## 升级与使用

1. 下载 `ObsidianPlanner-0.2.0-beta.1-macOS-arm64.zip`，退出旧 App，解压并替换「应用程序」中的 App。
2. **保留本机 Application Support 中的同步历史**，用于识别已有条目；不要为升级清空该目录。历史 JSON 与旧版兼容。
3. 必要时重新授予提醒事项权限；如果启用日历事件，日历权限需单独授权。
4. Preview 后逐条选择，再执行 Sync to DayPlanner。只改变通知设置时，也需要选择 Update existing 才会应用。
5. 部分失败后，先检查结果，再对未完成条目选择 Update existing 重试；选择 Add again 会明确创建另一份副本。

## 安装与限制

- **Apple silicon only**；构建目标 macOS 14+，其他系统／设备的完整兼容性尚未验证。
- **本地临时签名、未经 Apple 公证、无 Developer ID 签名。** 首次打开若被阻止，请核对来源后按系统设置 → 隐私与安全性 → 仍要打开处理。更新后可能需要重新授权。
- 同步仍为 Obsidian → 苹果单向，默认提醒事项、日历可选，不自动删除旧条目。
- 识别依赖这台 Mac 的历史；跨 Mac、Vault 移动及完整重装恢复尚未支持。
- 本次通过核心自动测试、Release 构建及原生 UI 检查；**新版逐条操作的真实 EventKit 写入、异常恢复及 iPhone 到达未重新完成端到端验证**。

## English

Preview now lets you choose an action for each schedule. New plans default to Add; previously exported plans default to Skip. Update existing reapplies source fields, including completion and notification settings. Add again keeps the old export and creates a new copy; future updates target that latest copy.

Keep your local sync history when upgrading. Unchanged previews keep choices; source/range/time-zone changes clear them. For partial failures, inspect the result and retry with Update existing rather than Add again. Calendar and Reminders now preserve separate notification history. Explicit skips and retired-copy matching are fixed.

Apple silicon beta, ad-hoc signed and not notarized. Target macOS 14+; cross-version runtime compatibility remains unverified. Core tests, Release build and native UI checks passed; real EventKit writes, failure recovery and iPhone delivery were not re-tested for this version. No Obsidian plugin is included.
