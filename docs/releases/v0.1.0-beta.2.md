## 安装 / Installation

下载 arm64 ZIP，解压后将 App 拖入应用程序。Apple silicon only；构建目标 macOS 14+，仅在 macOS 27.0.1 实测。未经 Apple 公证、无 Developer ID 签名；首次打开和升级可能需要通过系统设置中的“仍要打开”及重新授予提醒事项／日历权限。
