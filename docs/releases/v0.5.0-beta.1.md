# v0.5.0-beta.1 — Obsidian 内预览与同步

App **0.5.0 / build 6** · plugin **0.3.0** · bridge protocol **1** · 2026-11-18

**候选说明：** 本地自动检查、构建、候选包解压和只读原生检查通过；草稿附件上传后重新下载的校验和通过。新版真实写入及 iPhone 验收仍等待测试 Vault 的配对和系统授权。远端 CI 因平台／账户配置限制未启动，不计为通过。当前为 Release 草稿，尚未公开发布。

在 Obsidian 中预览已保存的 Day Planner 安排，逐条选择添加、跳过、更新或再次添加，再同步到苹果提醒事项和可选日历。匹配冲突可明确关联旧记录、创建新条目或跳过。插件与独立 Mac App 共用 Swift 解析器、执行器和原有本机历史。

This pre-release adds syncing from Obsidian with per-plan choices, explicit sync pairing, per-item results and status recovery. **Install the companion Mac App separately.** The plugin does not download native code; Apple permissions and account selection remain in the App.

## 首次使用与升级

1. 保留 `~/Library/Application Support/ObsidianPlanner/`，不要通过清空历史解决冲突。现有 App 历史继续沿用；App 仍可独立同步。
2. **先保存笔记编辑。** App 读取磁盘上的根目录 `YYYY-MM-DD.md` 日记。支持所配置 Day Planner 标题下的当天明确时间段：`- [ ] 09:00 - 10:00 Title` 或 `- [x] …`；无结束时间、跨午夜、嵌套等格式会提示跳过。
3. 从插件侧栏按钮或 Open Apple sync 命令选择范围、日程时区和选项。日期包含两端，每周从周一开始。
4. 点击 **Pair for preview + sync…**，并在 Mac App 确认准确的 Vault。**P2 只读配对不会自动获得同步权限，须在 App 重新批准。** 仅选择文件夹不等于批准。
5. 在 App 授予提醒事项权限、选择可写账户。日历为可选目标，使用独立日历权限和账户；仅提醒事项不依赖日历授权。默认提前 10 分钟提醒。
6. 点击 **Preview saved plans**，检查源日记链接、格式问题和每条选择，再以 **Sync selected** 提交所审阅的预览。源文件、配置或历史变化，以及 App 重启／预览过期，都需重新预览。

## 每条安排如何处理

- **Add：** 新安排默认添加；也可跳过。
- **Skip：** 已添加过的安排默认跳过，即使源标题、时间或完成状态改变。保留手机端修改时选此项。
- **Update existing：** 将日记中的标题、时间、完成状态及本次通知设置重新应用到关联条目，会覆盖对应的苹果端修改。
- **Add again：** 保留旧条目并创建新副本；后续更新关联最新副本。此选项不能用作普通失败重试。
- **Conflict：** 默认跳过。只有明确选定关联旧记录或创建新条目才处理。

执行一批同步后清除选择；范围、选项或来源改变也需重新审阅。同步是 **Obsidian → 苹果的单向操作**：不改写笔记，不把苹果端完成状态写回，不因源删除、缩小范围或关闭日历而自动删除旧条目。

## 结果、超时与恢复

结果按安排报告跳过、失败、未解决，以及提醒事项／日历各自的本机保存情况。**Mac 保存成功不表示 iPhone 已收到。** iPhone 到达和通知受 iCloud、同一 Apple 账户、网络及系统通知设置影响，需实际核对。

插件保留上次同步请求的本地指针，有限等待后可通过 **Check last sync** 查询原请求。关闭窗口、停用或重载插件只会停止观察；已经开始的原生写入可能继续完成。不会因为超时而自动以新 ID 再同步，也不会自动恢复 interrupted 请求。

遇到 partial、interrupted、not found 或结果尚未确认：先检查 Mac 提醒事项／日历，再刷新预览并审阅。已关联但未完成的条目以 **Update existing** 补写；不要选择 Add again 进行重试。请求／预览身份检查降低重复提交风险，但本机历史和两个苹果目标不是原子事务，**不承诺跨崩溃严格 exactly-once**。

## 本机数据与许可

插件偏好存于 Vault 插件设置。配对凭据、上次请求指针、App 授权书签、去重历史和近期结果收据存于同一 Mac 的私有 Application Support，不随普通 Vault 同步迁移。路径改变、换 Mac 或丢失历史没有透明恢复保证。请求含 Vault 路径、日期、时区、选项和本机凭据；结果可含标题和源位置，不复制整篇日记到桥接目录。URL 不携带凭据或笔记内容；无网络监听端口、遥测或自建服务器。

Forget on this Mac 清除插件客户端凭据；App 撤销配对阻止后续访问。两者不删除苹果条目或去重历史。该本机机制不能隔离同用户运行的恶意程序。
