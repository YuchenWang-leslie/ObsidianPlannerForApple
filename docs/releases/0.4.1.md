# 0.4.1 — Standard plugin release

Plugin **0.4.1** · unchanged helper **0.4.0** · Obsidian **1.15.1+** · Apple silicon / macOS **14+**

本版调整社区目录可识别的仓库与发行格式，并把 native helper 改为用户单独下载、手动安装。插件只检测和调用已经安装的 helper 0.4.0，不下载、复制、安装或更新它；不需要完整 ObsidianPlanner App。

**0.4.1 干净源码构建、62 项测试和本地打包验证通过。** [发行附件入口](https://github.com/YuchenWang-leslie/ObsidianPlannerForApple/releases/tag/0.4.1)。标准 manifest/tag/附件能供目录读取，不等于社区已经批准或可从 Browse 安装。旧版本的 helper 实测为历史证据，不冒充本轮 Apple 写入或 iPhone 验收。

## 发布结构

默认分支根目录提供 manifest、README、LICENSE、workspace 构建入口和 versions.json。manifest.version 与标准 GitHub tag 均为 `0.4.1`；versions.json 只声明 `0.4.1` → `1.15.1`。这是 [官方提交流程](https://docs.obsidian.md/plugins/releasing/submit-plugin) 所需的版本／附件对应方式。

| 发行附件 | 内容／用途 |
| --- | --- |
| `main.js` | 标准插件构建文件 |
| `manifest.json` | 0.4.1 manifest |
| `styles.css` | 插件样式 |
| `day-planner-apple-sync-0.4.1.zip` | 手动安装目录，只有 main.js、manifest.json、styles.css、README.md、LICENSE |
| `day-planner-apple-sync-helper-0.4.0-macOS-arm64.zip` | 单独的 helper 0.4.0，由用户手动安装 |
| `SHA256SUMS-plugin-0.4.1.txt` | 覆盖上述五个 payload 的 SHA-256；不包含校验文件自身 |

下载全部五项后可运行 `shasum -a 256 -c SHA256SUMS-plugin-0.4.1.txt`。插件 ZIP 不带 native 文件夹。旧 App 0.5.0/build 6、旧插件版本和所有既有 Release 附件不变。

## 新装与升级

新用户先按 [Helper setup](https://github.com/YuchenWang-leslie/ObsidianPlannerForApple/blob/main/docs/HELPER_SETUP.md) 解压 helper ZIP，手动把 **DayPlannerAppleSyncHelper.app** 放到：

```text
~/Library/Application Support/ObsidianPlanner/PluginRuntime/0.4.0/DayPlannerAppleSyncHelper.app
```

然后安装五文件插件 ZIP，启用后连接 Vault、分别授予所需权限和选择账户。helper 是无主窗口／Dock 项的 agent；其既有 ad-hoc 签名和未公证状态不变。系统阻止时按 [Apple 官方说明](https://support.apple.com/en-us/102445) 核对来源并处理，不弱化 Gatekeeper、不改 Obsidian Info.plist。

**已有 0.4.0 用户只升级插件**，保留现有 helper、系统权限、账户、PluginBridge 凭据、运行记录和共用历史。不要替换整个 Application Support/ObsidianPlanner 文件夹；它包含历史和令牌。缺失／不兼容时插件给出人工设置提示，不自动修复依赖。

共用历史、逐条选择和 Check last sync 机制保留。App／插件只顺序使用，不并发提交同步；不保证跨进程／崩溃严格 exactly-once。源笔记只读，先保存编辑；Mac 保存不等于 iPhone 到达。
