# App icon

Generated with the built-in imagegen tool, then packaged with sips and iconutil.

Design prompt: A premium macOS rounded-square icon for ObsidianPlanner. Deep ink-purple to luminous violet satin-glass tile, ivory planner card, two schedule lines and a lilac checkmark badge. Front-facing, generous spacing, no text or numbers, transparent exterior, readable at small sizes.

Source: AppIcon.png. Run `./scripts/build-icon.sh` to regenerate `Resources/AppIcon.icns` at standard macOS resolutions. The app build script copies the ICNS into the bundle; Info.plist declares it as AppIcon.
